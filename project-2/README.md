
# UIC CS 402 Fall 2025

## Project 2: Hashing
In this project, you will have practice with both Hashing problems. 
The implementations will be built off of concepts we have done in class up to this point.

**Please carefully read the algorithm descriptions in `Firstname_Lastname_project2.cpp`. You will need to implement the specified algorithms.**
The project includes
- `Firstname_Lastname_project2.cpp`
    - Your main file where you will implement most of your source code.
    It also contains the algorithm descriptions you will need to implement, so please read it carefully.

- `Firstname_Lastname_project2.h`
    - Header file with various function signatures.
    You can add things to the header/`.cpp` file as you need.

- `sha256.h` and `sha256.cpp`
    - These include implementations of the SHA256 function, which can be used to test your implementations.
    As given, they map strings to strings, which is useful for some of the functions you are asked to implement.
    For other integer valued functions, you may have to truncate the strings and convert to integers.
